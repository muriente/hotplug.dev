PROJECT GUIDE · NOVEMBER 2026

A direct connection.
A little setup first.

Hotplug is in development. This guide explains the intended experience and the questions we are working through. It is not a release or installation guide.

The idea

Share an Android phone’s internet with a computer or router through a USB data cable. After the initial installation and permissions, connecting the cable should start sharing on supported combinations, without manually turning on a hotspot or the phone’s USB tethering toggle.

What first-time setup involves

  1. Install Hotplug software on your Android phone and on the computer or supported router.
  2. Grant the Android permissions needed for the USB accessory connection and reliable background operation.
  3. Use a USB data cable. When Android asks to open the app for the accessory, the intended flow includes remembering that choice for later connections.
  4. Verify the connection on your specific devices before relying on it.

Exact steps and supported versions will be published with actual releases. Installation and system permission requirements may change as the project develops.

Current development focus

  • Android phones: the phone provides the internet connection.
  • Mac computers: a client handles the connected side.
  • OpenWrt routers: selected USB-capable routers are a development target.

This is a direction, not a verified compatibility list. There is no general availability claim, and no download is currently offered here.

What still matters

Your carrier’s terms, data allowance, signal quality, cable, USB port, phone behavior, and client device all affect the experience. Hotplug does not promise faster internet, unlimited data, a charging-only connection, or support for every device. Shared internet still depends on the phone’s upstream network.

Help shape the project

Use GitHub Discussions for setup ideas and questions. Include device models, operating system versions, and the situation you want to improve. Do not post passwords, tokens, phone numbers, IP addresses, or unredacted logs.

Use website issues for broken links, accessibility problems, or inaccurate website content. We will share development updates through the project discussions.

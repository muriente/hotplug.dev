# Security

This repository contains the Hotplug website, not the Hotplug software.

Use [private vulnerability reporting](https://github.com/muriente/hotplug.dev/security/advisories/new) for sensitive website security reports. A GitHub account is required. Include affected URL, impact, and minimal safe reproduction steps. Do not include working credentials or personal information. Avoid public issues for unpatched vulnerabilities.

Only the current deployed website is supported here. There is no guaranteed response deadline or bounty program. Product vulnerability reporting will be documented with actual software releases; this repository is not a statement of software availability.

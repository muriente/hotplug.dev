# Contributing

For website corrections, use an issue or pull request. For project direction and intended device setups, use [Discussions](https://github.com/muriente/hotplug.dev/discussions). No downloads or verified compatibility list are published yet.

Keep copy English and use Hotplug capitalization. Explain first-time installation and permissions; do not promise universal compatibility, speed advantages, permanent pricing or public software source. Never post credentials or unredacted logs.

Run `npm ci --ignore-scripts`, `npx playwright install chromium`, `npm test`, and `npm run test:browser`. Preview using `npm run preview`. Make small PRs that state visitor impact and validation. PRs require passing Site checks but no approval from another person, so a single maintainer can operate the site. Website code is MIT licensed; that does not license the separate product or grant trademark rights.

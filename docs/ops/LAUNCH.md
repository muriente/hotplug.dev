# Hotplug website launch

Juan Muriente published the first Hotplug website on November 4, 2026. The site introduces the project, describes the intended setup and invites feedback. The launch covered the website. The website license applies to its code and assets.

GitHub Pages serves the site at [hotplug.dev](https://hotplug.dev). The site uses HTTPS and redirects www links to the same path on the apex domain. The launch checks covered the guide, privacy page, keyboard navigation, mobile layout and automated accessibility tests. [Launch verification](https://github.com/muriente/hotplug.dev/issues/8)

For later releases, read the published source commit in the [live version manifest](https://hotplug.dev/version.json). The maintainer’s guide covers the checks, deployment and rollback steps. [Publication procedure](LOCAL-PUBLICATION.md)

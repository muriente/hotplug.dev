WEBSITE PRIVACY · NOVEMBER 4, 2026

A small website.
A small footprint.

This page describes hotplug.dev, not the future Hotplug software.

What this site uses

The site serves static files. It has no analytics scripts, advertising, embedded social widgets, account system, or forms. It does not set application cookies or use browser storage. Fonts and illustrations are served with the site.

Hosting and network providers

GitHub Pages hosts the website. Cloudflare provides DNS and may proxy requests for delivery and security. These providers can process connection information such as IP addresses, request paths, and browser headers as part of their services; security systems may use cookies or challenges.

See GitHub’s privacy statement and Cloudflare’s privacy policy for their practices.

When you follow a GitHub link

Discussions, issues, and contribution pages are on GitHub. GitHub’s account and privacy rules apply there. Public posts are visible to others. Please keep credentials and personal data out of public reports.

Questions or corrections

You can report a website issue. For sensitive security details, use the private security reporting route.
